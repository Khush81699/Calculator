# 🧮 Calculator Web App

A simple and responsive Calculator built using **HTML, CSS, and JavaScript**.  
This project performs basic arithmetic operations and demonstrates **DOM manipulation and event handling in JavaScript**.

---

## 📖 Project Overview

The Calculator Web App allows users to perform basic mathematical calculations through a simple and interactive user interface. Users can input numbers and operators using calculator buttons, and the result is displayed instantly.

This project helps in understanding **frontend development concepts and JavaScript logic building**.

---

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖ Multiplication
- ➗ Division
- % Percentage
- AC (All Clear) button
- DEL (Delete last value) button
- Error handling for invalid expressions
- Clean and responsive user interface

## 💡 How It Works

1. The user clicks numbers and operators on the calculator interface.
2. The selected values appear on the calculator display.
3. JavaScript functions perform the following tasks:
   - Appending numbers and operators
   - Clearing the display
   - Deleting the last entered value
   - Calculating the result
4. The final result is displayed on the screen.

Error handling ensures invalid calculations do not break the application.
