# 🧮 Calculator Web App

A simple and responsive Calculator built using HTML, CSS, and JavaScript.  
This project performs basic arithmetic operations and demonstrates DOM manipulation and event handling in JavaScript.

---

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖ Multiplication
- ➗ Division
- % Percentage
- AC (All Clear) button
- DEL (Delete last value) button
- Error handling for invalid expressions
- Clean and user-friendly interface

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

calculator/

---

## 💡 How It Works

- The calculator takes input from button clicks.
- JavaScript functions handle:
  - Appending numbers and operators
  - Clearing the display
  - Deleting last character
  - Calculating the result
- The result is displayed inside the input field.
- Error handling is implemented using try-catch.

---

## ▶️ How to Run the Project

1. Download or clone the repository
2. Open the project folder
3. Double-click on `index.html`
4. The calculator will open in your browser
